# monolith-release

Binary distribution repository for the Nife monolith agent (source: [nifetency/nife-monolith-agent](https://github.com/nifetency/nife-monolith-agent)) — part of the [Nife](https://nife.io) platform.

This repo hosts pre-built release binaries only. For source code, issues, and contributions, see [nifetency/nife-monolith-agent](https://github.com/nifetency/nife-monolith-agent).

## Download

Grab the latest release from the [Releases page](https://github.com/nifetency/monolith-release/releases/latest). Builds are available for:

- Linux (x86_64)
- Windows (x86_64)
- macOS (Intel / x86_64)
- macOS (Apple Silicon / arm64)

## Installation

```bash
# Example for Linux x86_64
curl -LO https://github.com/nifetency/monolith-release/releases/latest/download/app-linux-x86_64.tar.gz
tar -xzf app-linux-x86_64.tar.gz
```
